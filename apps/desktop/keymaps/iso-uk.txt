# Tracker Cycles desktop keymap: UK ISO keyboard (the default).
# See apps/desktop/PLAN.md, "Keyboard mapping" and "Keymaps are data".
#
#   [ctrl] [alt] [shift] [hold] KEY = TARGET [| TARGET ...]   [# comment]
#
# KEY is a physical key (SDL scancode name: F1, Q, 1, Left, PageUp,
# Return, Left Alt, ...; NonUSBackslash = the key left of Z), so the
# map is the same whatever layout the OS uses.
# TARGET is
#   CONTROL          a Tracker control (ids from tidal/editor/controls.cpp:
#                    s1..s8, pad1..pad48, play, insert, fx1, jog+, ...)
#   shift CONTROL    the control with Shift
#   action NAME      the Tracker control that does NAME here, if any (ok,
#                    cancel, ...: action names from tidal/editor/editor.cpp)
#   app NAME         a desktop-only command (quit, hush, nextslot,
#                    prevslot, type, settings)
# Alternatives (|) are tried left to right; the first that applies wins.
# Shift passes through: "F3 = s3" also makes Shift+F3 = Shift+Screen 3.
# "hold" keys press the control while held (Alt = the Pattern button).
