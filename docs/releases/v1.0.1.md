# Tracker Cycles 1.0.1

**Live-code TidalCycles-style patterns on the Original Polyend Tracker. No computer needed.**

Tracker Cycles is a free firmware that turns the Original Tracker into a standalone live-coding instrument. You write real Tidal code, such as `d1 $ every 4 (fast 2) $ s "bd*2 [~ sd]" # room 0.3`, edit it with the pads, jog wheel and buttons, and the Tracker's own sample engine plays it. There's no SuperCollider and no GHC: the whole pattern engine runs on the Tracker.

This is the first public release. 1.0.1 is 1.0.0 with the licence finalised and the example project withdrawn for now (see below).

## Highlights

* **Real Tidal, on the device.** About 140 functions, controls and operators, from `fast`, `every` and `jux` to `within`, `fix`, `ghost` and `qtrigger`, with full mini-notation. Every function is checked against Tidal 1.10.3's own output: 284 cases, all matching.
* **An editor made for pads and a jog wheel.** You edit the code's structure, so it's always valid, and every menu only offers what fits.
  * Cursor mode moves like a text editor; tree mode moves through the structure. Rec switches between them.
  * The jog wheel changes values in musical steps.
  * The pads are a keyboard, your 48 instruments, or chords.
  * One press adds brackets, euclid rhythms, `*2`, `!`, `@`, `?` or a new layer.
* **Made to perform.**
  * Play evaluates a block; hold Pattern and press pads to mute and solo.
  * Steps light up as they sound, and a block flashes when it's accepted.
  * Launch modes, several blocks per track, and tempo with `setcps`.
* **The Tracker's sound, driven by Tidal.**
  * Controls map onto the Tracker's engine: `gain`, `pan`, filters, reverb and delay, `crush`, `shape`, sample start / end, envelopes, pitch and slices.
  * Up to 3 overlapping notes per track, added for you when you use `jux`, `off`, echoes or chords.
  * Tidal-style sample folders, so `s "bd:3"` works.
* **MIDI** on d9–d16: notes, chords, CCs, pitch bend, program changes and aftertouch, plus clock out following `setcps`.
* **Your code is saved with the project** as a plain `.tidal` file, and autosaved after every edit.

## Install

1. Download `PolyendTracker_Cycles_1.0.1.ptf` below and copy it to `/Firmware/` on the Tracker's SD card.
2. On the Tracker: **Config → Firmware → Firmware update**, select the file and confirm.
3. After the reboot, **Config → Firmware** shows `tracker-cycles 1.0.1`.

Back up your SD card first. Tracker Cycles has no patterns or songs: it opens a project's instruments, samples and settings and adds its code. Stock projects stay openable in the stock firmware. If anything ever goes wrong, flash a known-good firmware with the bootloader: see [Recovery](https://github.com/CyopStudio/tracker-cycles#recovery).

**Getting started:** press **Shift + pad 1** to go to `d1`, then **Instrument** to start a block with your first sample. Turn the jog wheel, tap pads, and press **Play**. The [README](https://github.com/CyopStudio/tracker-cycles#readme) has all the controls.

* **Example project withdrawn.** Its samples came from the Tracker's stock library, which may not be ours to share. A new example project is coming.

## Known limitations

* Original Tracker (MK66) only.
* No SuperCollider synths. Playback speed is approximated with tuning, and the reverb and delay are shared by all tracks. `chop` and `striate` aren't available on the device yet.
* No lambdas, `let` or user-defined functions; tuples are pairs only.
* Random functions follow Tidal's probabilities but produce different values.
* At most 48 instruments and about 7.5 MB of sample memory.
* Loading a sample folder can pause the screen briefly, so load folders before a performance.
* While several patterns play, a menu with many choices can take a moment to finish checking.

The full list of changes is in [CHANGELOG.md](https://github.com/CyopStudio/tracker-cycles/blob/main/CHANGELOG.md).
