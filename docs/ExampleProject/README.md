# Example project: tracker-cycles1

A complete Tracker Cycles project to try on your Tracker: 14 instruments (808 kit, bass, pad, a vocal and a loop) and `tracker-cycles1.tidal` with two blocks for most tracks (d1–d7), a `setcps` of 160 BPM and a few of the editor's favourite moves (`every'`, `whenmod`, `jux`, `ply`, `splice`, `jumpMod`).

## Install

1. Unzip `tracker-cycles1.zip` into `/Projects/` on the Tracker's SD card, so you get `/Projects/tracker-cycles1/`.
2. On the Tracker: **File → Open project → tracker-cycles1**.
3. Press **Play** on a block to start it; **Shift + Up / Down** moves between blocks.

The `.pti` instrument files hold the samples themselves: no WAV files are needed. The samples are the author's own and are included for trying out Tracker Cycles.
